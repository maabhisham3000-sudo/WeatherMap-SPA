"# WeatherMap SPA"  
# Project Name:

WeatherMap SPA

# A simple Description:

WeatherMap SPA is a modern, asynchronous single-page web application built entirely from scratch using HTML5, Bootstrap 5, CSS3, and Vanilla JavaScript. It integrates multiple APIs (OpenWeatherMap for current weather and 5-day forecasts, and Nominatim for geocoding) with Leaflet.js interactive mapping to provide a seamless, responsive, and user-friendly weather exploration experience complete with Dark Mode support and local clipboard sharing features.

# Technologies:

HTML5 | CSS3 | JavaScript (ES6+, Async/Await, Fetch API) | Bootstrap 5 | Leaflet.js | OpenWeatherMap API | Nominatim Geocoding API | GitHub Pages

# How to run:

1. Clone or download the project repository to your local machine.
2. Open the project folder using any code editor (such as Visual Studio Code).
3. Use a local development server extension (like Live Server in VS Code) to run the project.
4. Alternatively, open the `index.html` file directly in any modern web browser.
5. Access the live hosted version directly via GitHub Pages.
